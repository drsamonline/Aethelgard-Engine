# Aethelgard — icon prompts — combat skills

The 25 combat skills. They appear on the action bar during every fight, so this is the set the player sees most.

**25 icons. Generate each at 1:1, on a completely plain flat solid magenta
background** — that is what lets me cut them out. No floor, no shadow, no scene,
no second colour. Save each under the exact filename in its heading.

Everything here is optional: skip any icon and that entry keeps the emoji it
shows today. Send them in any batch size.

---

### Where these go

`skill_<key>.png` becomes `skill.<key>` — e.g. `skill_fireball.png` fills `skill.fireball`.
